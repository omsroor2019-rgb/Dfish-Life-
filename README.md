# DFISH LIVE — Flutter Android

تطبيق عربي RTL لكرة القدم ومصادر المشاهدة المرخصة، بهوية مستقلة: `DFISH` أبيض و`LIVE` أخضر فسفوري. الخط IBM Plex Sans Arabic، وأيقونات Lucide المتجهية وليست ملصقات أو رموزاً تعبيرية.

## الموجود في المشروع

- الرئيسية وجدول مباريات اليوم، مع توقيت اليمن `Asia/Aden`.
- عرض مباريات حسب التاريخ ومرشحات مباشر/قادمة/منتهية.
- مركز المباراة: الأحداث، التشكيلات والإحصائيات عندما يغطيها مزود البيانات.
- البطولات والترتيب والهدافون وصناع الأهداف.
- البحث عن اللاعبين والأندية وصفحات معلوماتهم وسجل انتقالات اللاعب.
- جلب شعارات الفرق والبطولات وصور اللاعبين من حقول API-Football.
- قسم بث بمباريات يضيفها المدير، مع حتى أربعة مصادر لكل مباراة.
- مشغل داخل التطبيق لروابط الفيديو المباشرة HLS `.m3u8` وMP4؛ التشغيل يبدأ بعد ضغط المستخدم. روابط صفحات HTTPS تفتح داخل WebView مدمج ومقيّد على نفس النطاق في التنقل الرئيسي، ولا يتم استخراج stream داخلي منها.
- بوابة إدارة مخفية داخل صفحة الإعدادات (سبع نقرات على الإصدار)، ومحمية بكلمة مرور + TOTP من الخادم.
- تخزين جلسة المدير في Android secure storage.
- Cloudflare Worker + D1 لإدارة الحساب والمباريات وروابط البث، وKV لكاش API-Football.
- سقف مركزي 90 طلب API خارجي يومياً بعد الكاش، لحماية حصة الخطة المجانية وترك 10 طلبات احتياطية.
- GitHub Actions لإنتاج APK.

## ما لا تدّعيه هذه النسخة

- API-Football يوفر بيانات رياضية لا فيديو بث المباريات.
- لا يوجد مصدر مجاني واحد يمنح حقوق مكتبة أفلام ومسلسلات عالمية؛ قسم الأفلام لم يتم تفعيله بمحتوى تشغيل.
- لم تُدمج بعد مكتبة بث تلفزيوني عالمية أو كتالوج أفلام/مسلسلات داخل التطبيق.
- قسم الأخبار يفتح مواقع الناشرين الرسمية ولا ينسخ مقالاتهم؛ لم يتم دمج موجز أخبار موحد بعد.
- التنبيهات الفورية عبر FCM غير مفعلة بعد.
- المفضلة الحالية تحفظ علامة المباراة محلياً؛ لم تُبنَ بعد شاشة مكتملة لإدارة كل المفضلات.
- التشكيلات والإحصائيات والإصابات والانتقالات تختلف تغطيتها حسب المسابقة والموسم.
- الروابط التي يضيفها المدير يجب أن يكون مسموحاً له بعرضها. صفحة Blogger أو مشغل طرف ثالث ليست بالضرورة رابط HLS مباشر ولا تعني امتلاك حقوق إعادة البث.

## الإعداد للمرة الأولى

1. ألغِ مفتاح API-Football الذي ظهر في المحادثة وأنشئ مفتاحاً جديداً.
2. اتبع [دليل إعداد Cloudflare بالعربية](CLOUDFLARE_SETUP_AR.md) لإنشاء D1 وKV وWorker وربط أسرار API. نفّذ هجرتي قاعدة البيانات `0001_admin_and_streams.sql` ثم `0002_api_daily_usage.sql` بالترتيب.
3. أنشئ مستودع GitHub وارفع محتويات المجلد إلى جذره.
4. أضف GitHub Actions Variable باسم `API_BASE_URL` يساوي رابط Worker.
5. شغّل workflow باسم **Build DFISH LIVE APK** من تبويب Actions.
6. نزّل Artifact باسم `DFISH-LIVE-Android-APK`.
7. بعد تثبيت التطبيق، أعد إعداد الإدارة من مكان الدخول المخفي الموضح في الدليل.

## أمان لوحة الإدارة

- لا توجد كلمة مرور أو مفتاح TOTP ثابت في كود Flutter.
- اشتقاق كلمة المرور PBKDF2-HMAC-SHA256/600,000 يتم على الجهاز، وترسل قيمة مشتقة مملحة عبر HTTPS بدلاً من كلمة المرور النصية.
- تسجيل الدخول يستخدم تحدياً عشوائياً أحادي الاستخدام مرتبطاً بعنوان الشبكة وإثبات HMAC مشتقاً من كلمة المرور؛ الخادم لا يستقبل كلمة المرور النصية عند تسجيل الدخول.
- Worker يتحقق من رمز TOTP ويمنع إعادة استخدام عداد الرمز ويصدر جلسة عشوائية قصيرة نسبياً؛ يخزن بصمة الجلسة فقط في D1.
- رمز TOTP مخزن مشفراً بـAES-GCM باستخدام Secret مستقل في Cloudflare.
- جلسة المدير محفوظة في `flutter_secure_storage`.
- نقطة الدخول المخفية مجرد تقليل للظهور؛ الحماية الحقيقية في المصادقة والتحقق من صلاحيات كل endpoint.
- لا يوجد ضمان أمني مطلق. اختبر الخادم وسجلاته، واحتفظ بأسرار الاستعادة، واطلب مراجعة أمنية قبل الإطلاق العام.
- لوحة الإدارة المخفية ليست حدّاً أمنياً؛ كل مسار إداري يتحقق من الجلسة على الخادم.

راجع [نموذج الأمان بالعربية](docs/SECURITY_MODEL_AR.md) لشرح التفعيل الأولي وحماية الجلسات والأسرار.

## الملاحظات الفنية

- Flutter/Dart: يتطلب Dart 3.13+ بسبب إصدارات الحزم الحالية. الحد الأدنى المستهدف لـ Android هو SDK 24 (Android 7.0+) لدعم مشغل الفيديو وWebView.
- API-Football: 100 طلب يومياً، و10 طلبات في الدقيقة على الخطة المجانية؛ الكاش يقلل تكرار الطلبات لكنه لا يلغي الحدود.
- Cloudflare Free: له حدود يومية منفصلة لطلبات Worker وD1 وKV؛ تجاوز الحصص قد يوقف العمليات حتى التجدد.
- لا نضع مفاتيح API في APK أو مستودع GitHub.
- الشعارات والصور تأتي من API-Football؛ تحقق من حقوق العلامات والشعارات قبل إعادة نشر التطبيق.

## حالة التحقق

تم تنفيذ فحوص بنيوية لملفات المشروع وJavaScript/YAML، لكن Flutter SDK غير متاح في بيئة إعداد هذه الحزمة. لم يتم تشغيل `flutter pub get` أو `flutter analyze` أو بناء APK محلياً. يتم التحقق الفعلي عند تشغيل GitHub Actions، ويجب إصلاح أي خطأ بناء يظهر قبل اعتبار APK إصداراً جاهزاً.


### تشغيل روابط المباريات

يدعم المشغل روابط HLS المباشرة بصيغة M3U8 وMP4، وتظهر مستويات جودة HLS إن وفّرها المصدر والمنصة. كما تُفتح صفحات HTTPS داخل WebView مقيّد على نفس النطاق في التنقل الرئيسي، مع إمكانية تحميل إطارات HTTPS المضمّنة اللازمة للمشغل. لا يقوم المشروع باستخراج روابط مخفية أو تجاوز الإعلانات/DRM أو تسجيل الدخول أو القيود الجغرافية. قد لا تعمل بعض المواقع داخل WebView.
